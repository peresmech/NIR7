# Ресурсы приложения

Папка хранит локальные исходные данные и справочники программы:

- `hydro.db` — начальная SQLite-база наблюдений;
- `stations.csv` — справочник гидроузлов и гидропостов;
- `hydrogis.ico` — иконка приложения Windows (метка и русло реки);
- `network_edges.geojson` — локальные русловые линии для офлайн-карты;
- дополнительные файлы источников и служебные справочники.

При первом запуске база копируется из этой папки в `data/hydro.db`.
Пользовательские изменения сохраняются только в локальной папке `data`;
исходные файлы в `resources` не перезаписываются.
Русловая сеть содержит данные OpenStreetMap; атрибуция © OpenStreetMap
contributors, лицензия ODbL.
